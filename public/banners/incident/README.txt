Incident messaging banners
==========================

Extracted from the previous standalone tool (https://sndm-em.github.io/Incident-Messaging/),
where they were embedded as base64 data URIs. Kept byte-identical so the imagery the
route already recognises carries over to the new incident messaging section.

See docs/incident-messaging/SPEC.md §5 for the mapping of each file to its
lifecycle phase, severity, and the old tool's constant name.
